The collection originated in 1993; the bundled files are the 128 color TIFFs
from Pixar's official 2018 re-release, byte-for-byte unchanged. Test charts and
later bump/normal maps are excluded. RetroMan adds the material node presets and
catalog. These images remain **CC BY 4.0**, separately from the engine's GPL code.

Retain credit and license/source links when redistributing these textures or
adaptations, and identify changes. The in-scene credit text provides a reusable
attribution. No Pixar endorsement or affiliation is implied.

## Native cross-build runtimes
Windows/macOS release libraries are cross-compiled using Zig 0.14.1 (https://ziglang.org/) and its bundled LLVM C++ runtime components. Windows also uses MinGW runtime code. Applicable copyright notices and licenses are included in native/licenses/. The compiler itself is not bundled.
